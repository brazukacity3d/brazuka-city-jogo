# Brazuka City

Construtor de cidade 3D brasileiro: comece numa Vila e cresça até a Mega Brazuka, com ruas, casas, comércio, fazendas, trens, porto, aeroporto e moradores andando pelas calçadas.

**Jogar:** https://brazukacity3d.github.io/brazuka-city-jogo/

## No celular, como app
- **iPhone:** abra o link no Safari, toque em **Compartilhar** (o quadrado com a seta) e escolha **Adicionar à Tela de Início**. Abrindo pelo ícone, o jogo ocupa a tela toda.
- **Android:** abra o link no Chrome, toque no menu (⋮) e escolha **Instalar app** ou **Adicionar à tela inicial**. O jogo abre em tela cheia e deitado.
- Depois da primeira abertura, o jogo funciona até sem internet.

Este repositório guarda só o jogo pronto para jogar.
